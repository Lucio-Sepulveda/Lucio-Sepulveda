## XR & Serious Games Projects

### [VR Cognitive Training Maze *(in development)*](https://github.com/Lucio-Sepulveda/vr-cognitive-training-maze)
A VR maze application for Meta Quest built in **Unity/C#**, designed for cognitive training with adaptable difficulty. A **Python** module generates mazes procedurally with adjustable parameters and exports them to Unity, which assembles the geometry at runtime from custom Blender assets. Currently building a local-network layer so a clinician's interface can push new layouts and modify the maze in real time while the player is inside the headset.

`Unity` `C#` `Meta XR SDK` `Python` `Blender`

---

### [Lumbar Puncture VR Simulator *(in development)*](https://github.com/Lucio-Sepulveda/lumbar-puncture-vr-simulator)
A medical training simulator in **Unity/C#** for Meta Quest 3, developed alongside the Faculty of Engineering (UNER) and Hospital San Martín de Paraná. Features a haptic feedback system using the **Haply Inverse3** device that simulates distinct tissue resistances at multiple anatomical depths. Built in close collaboration with physicians — clinical requirements → technical specs, iterative usability tests, parameter tuning based on medical feedback.

`Unity` `C#` `Meta XR SDK` `Meta Quest 3` `Haply Inverse3`

---

### [MicroGestures AR Arcade Game](https://github.com/Lucio-Sepulveda/microgestures-ar-game)
A controller-free AR arcade shooter for **Meta Quest 3**, built in **Unity/C#** using Meta's MicroGestures API. Swipe to move, tap to shoot — no controllers. Implemented a spatial AR display system that anchors a virtual screen to the player's hand in physical space. Iterated on gesture mapping to reduce input latency and improve responsiveness.

`Unity` `C#` `Meta XR SDK` `MicroGestures API` `Passthrough AR`

---

### Cognitive Training App for Athletes
A full **Android** application built in **Godot Engine** for high-performance athlete cognitive training. Developed in collaboration with a sports psychologist and a graphic designer — managed the full cycle from prototype to a functional product actively used by sports professionals.

`Godot` `GDScript` `Android`

---

### [TrendetecT — Trendelenburg Test Analysis](https://github.com/Lucio-Sepulveda/trendetect-trendelenburg-test)
A computer vision desktop tool (**Python / OpenCV / PySide6**) for objective biomechanical analysis of the Trendelenburg test using ArUco marker tracking. Extracts biomechanical metrics automatically (max/min/average angles, test duration) and exports clinical data to CSV. Currently in validation with physiotherapy professionals at Hospital de la Baxada.

`Python` `OpenCV` `PySide6` `ArUco`
